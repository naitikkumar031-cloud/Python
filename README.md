## 📖 Overview
This repository contains all 10 practical lab assignments completed for the **Python Application Programming** course. Each Jupyter Notebook (`P_1.ipynb` through `P_10.ipynb`) includes problem statements, clean Python implementations, execution outputs, and analytical interpretations.

## 📂 Practical Index

| No. | Notebook | Practical Topic | Key Concepts Covered |
| :--- | :--- | :--- | :--- |
| 01 | [`P_1.ipynb`](P_1.ipynb) | **Foundational Concepts** | `print()` statements, comments, data types (`int`, `float`, `str`, `bool`), type casting, arithmetic operators, and time conversion (`//`, `%`). |
| 02 | [`P_2.ipynb`](P_2.ipynb) | **Strings & Lists** | List creation, `.append()`, positive/negative indexing, element modification, and `.remove()`. |
| 03 | [`P_3.ipynb`](P_3.ipynb) | **Dictionaries & Tuples** | **Dictionaries:** Nested structures, `.items()` iteration, membership checks, and key deletion.<br>**Tuples:** `max()`, `min()`, `sum()`, `sorted()`, and immutability (`TypeError`). |
| 04 | [`P_4.ipynb`](P_4.ipynb) | **Conditions, Branching & Loops** | Filtering dictionary records with `if-else`, even/odd checks, palindromes, digit-sum divisibility, `for` loops with `range()`, and `while` loops with `break`. |
| 05 | [`P_5.ipynb`](P_5.ipynb) | **Error Handling** | `try-except` blocks for `ZeroDivisionError`, raising/catching `ValueError` for invalid inputs, and generic `Exception` handling. |
| 06 | [`P_6.ipynb`](P_6.ipynb) | **Classes, Objects & Logic** | Fixing inheritance with `super()`, anagram verification, Armstrong number checking, and building a `Vehicle` class with methods. |
| 07 | [`P_7.ipynb`](P_7.ipynb) | **Polymorphism & Encapsulation** | Magic methods (`__init__`, `__repr__`), inheritance (`Animal` → `Dog`), polymorphism (`Cat`, `Fox`), and encapsulation with private attributes (`__score`). |
| 08 | [`P_8.ipynb`](P_8.ipynb) | **NumPy & Pandas** | DataFrame creation, column selection, `head()`, `describe()`, `isnull().sum()`, missing value imputation (`fillna()` with mode/median), filtering, `groupby()`, and sorting. |
| 09 | [`P_9.ipynb`](P_9.ipynb) | **Data Cleaning & File I/O** | Context-managed file handling (`with open()`) to interleave string pairs into a file, and parsing/reformatting `MM/DD/YYYY` date strings. |
| 10 | [`P_10.ipynb`](P_10.ipynb) | **Data Visualization** | Exploratory visualization and correlation analysis of the **Iris dataset** using Seaborn & Matplotlib (Scatter, KDE Density, Violin, Heatmap, Joint, and Pair plots). |
